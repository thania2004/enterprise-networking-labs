# Simple Networking Project

## Overview

This project focuses on the design and implementation of a basic computer network using Cisco Packet Tracer.

The objective is to build a functional network infrastructure, configure network devices and establish communication between connected devices.

## Technologies & Concepts

- Cisco Packet Tracer
- Basic Switching and Routing
- IPv4 Addressing
- Subnetting
- Cisco IOS CLI
- Network Connectivity Testing

## Project Files

- `packet-tracer/`: Packet Tracer project files.
- `documentation/`: Network topology and technical documentation.
- `configurations/`: Device configuration files.
- `screenshots/`: Network topology and testing evidence.

## Implementation

Project documentation and network configurations will be added as the implementation progresses.

## Learning Objectives

- Understand basic network infrastructure.
- Configure routers and switches.
- Apply IPv4 addressing concepts.
- Verify connectivity between network devices.
