# Campus Network Design & Implementation

## Overview

This project focuses on the design and implementation of a campus network infrastructure using Cisco Packet Tracer.

The objective is to build a scalable and structured network capable of connecting multiple buildings, departments and end devices through an integrated network architecture, ensuring efficient communication and reliable connectivity.

## Technologies & Concepts

- Cisco Packet Tracer
- Enterprise Network Architecture
- Hierarchical Network Design
- VLAN Configuration and Management
- Inter-VLAN Routing
- IPv4 Addressing and Subnetting
- Switching and Routing
- Spanning Tree Protocol (STP)
- Network Connectivity Testing

## Project Files

- `packet-tracer/`: Packet Tracer project files.
- `documentation/`: Network topology and technical documentation.
- `configurations/`: Router and switch configuration files.
- `screenshots/`: Network topology and connectivity test evidence.

## Implementation

Network topology, infrastructure design, device configurations and implementation details will be documented throughout the project.

## Learning Objectives

- Understand large-scale campus network architecture.
- Design hierarchical network infrastructures.
- Connect multiple buildings and network segments.
- Configure switching and routing technologies.
- Understand network segmentation and traffic management.
- Verify network connectivity and infrastructure functionality.
