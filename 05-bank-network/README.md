# Banking Network Design & Implementation

## Overview

This project focuses on the design, implementation and configuration of a banking network infrastructure using Microsoft Visio and Cisco Packet Tracer.

The objective is to design a structured and reliable enterprise network capable of supporting banking operations, internal communications and interconnected departments while addressing essential requirements for network security, availability and efficient resource management.

The project is divided into three main phases, covering network modelling, infrastructure implementation and banking network services.

## Project Phases

### Phase 1 — Network Modelling & Architecture

Design and documentation of the proposed banking network infrastructure using Microsoft Visio.

- Enterprise Network Architecture
- Network Topology Design
- Infrastructure Planning
- Network Device Distribution
- Logical Network Design

### Phase 2 — Network Implementation

Implementation of the designed network topology using Cisco Packet Tracer.

- Cisco Router and Switch Configuration
- LAN and WAN Networking
- IPv4 Addressing and Subnetting
- VLAN Configuration and Network Segmentation
- Inter-VLAN Routing
- Routing Configuration
- DHCP and Network Services
- Network Connectivity Testing

### Phase 3 — Banking Network Services

Configuration and integration of network services required to support the banking environment.

- Server Infrastructure
- Network Services Integration
- Client-Server Communication
- Network Resource Management
- Access Control and Traffic Filtering
- Network Security Fundamentals

## Technologies & Tools

- **Cisco Packet Tracer:** Network simulation and infrastructure implementation.
- **Microsoft Visio:** Network architecture modelling and topology design.
- **Cisco IOS CLI:** Router and switch configuration.
- **TCP/IP:** Network communication protocols.
- **IPv4:** Addressing and subnetting.
- **VLANs:** Logical network segmentation.
- **Routing & Switching:** Network connectivity and traffic forwarding.
- **DHCP / DNS:** Network addressing and name resolution services.
- **ACLs:** Network traffic filtering and access control.

## Project Structure

- `01-network-modelling/`: Network architecture and Visio diagrams.
- `02-packet-tracer/`: Cisco Packet Tracer implementation files.
- `03-banking-network-system/`: Banking network services and configuration documentation.
- `configurations/`: Device configuration files.
- `documentation/`: Technical documentation and network addressing plans.
- `screenshots/`: Network topology and implementation evidence.

## Security Considerations

Special attention is given to the security requirements of banking infrastructure, including:

- Network segmentation and isolation.
- Controlled communication between network segments.
- Access control and traffic filtering.
- Secure network administration.
- Infrastructure availability and reliability.

## Learning Objectives

- Understand the architecture of enterprise banking networks.
- Design and model complex network infrastructures.
- Implement network topologies using Cisco Packet Tracer.
- Configure routers, switches and network services.
- Apply network segmentation and access control principles.
- Understand the importance of security and availability in critical IT infrastructures.
