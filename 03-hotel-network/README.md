# Hotel Network Design & Implementation

## Overview

This project focuses on the design and implementation of a hotel network infrastructure using Cisco Packet Tracer.

The objective is to develop a structured network environment capable of supporting different hotel departments, guest connectivity and internal communication services while ensuring reliable network operations.

## Technologies & Concepts

- Cisco Packet Tracer
- Enterprise Network Design
- LAN Architecture
- VLAN Configuration
- Network Segmentation
- IPv4 Addressing and Subnetting
- Routing and Switching
- DHCP Configuration
- Network Connectivity Testing

## Project Files

- `packet-tracer/`: Packet Tracer project files.
- `documentation/`: Network topology and technical documentation.
- `configurations/`: Router and switch configuration files.
- `screenshots/`: Network topology and connectivity test evidence.

## Implementation

Network topology, device configurations and implementation details will be documented throughout the project.

## Learning Objectives

- Understand enterprise hotel network architecture.
- Design network infrastructure for different hotel departments.
- Implement network segmentation.
- Configure network devices and communication services.
- Verify connectivity and network functionality.
