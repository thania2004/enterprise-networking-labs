# Company Network Design & Implementation

## Overview

This project focuses on the design and implementation of a company network infrastructure using Cisco Packet Tracer. It explores how to build and configure an enterprise network to support communication between different departments, devices and network services.

## Technologies & Concepts

- Cisco Packet Tracer
- Enterprise Network Design
- LAN Architecture
- Network Topology
- IPv4 Addressing and Subnetting
- Switching and Routing
- VLAN Configuration
- Inter-VLAN Routing
- DHCP and DNS Services
- Network Connectivity and Troubleshooting

## Project Files

- `packet-tracer/` – Network simulation files.
- `documentation/` – Network architecture and technical documentation.
- `configurations/` – Router and switch configuration files.
- `screenshots/` – Screenshots of the network topology and implementation.

## Implementation

The project involves designing the network topology, configuring network devices, establishing communication between different network segments and implementing the services required for the company's infrastructure.

## Learning Objectives

- Understand the architecture of an enterprise company network.
- Design and implement a structured network topology.
- Configure routers, switches and network services.
- Apply IP addressing and subnetting techniques.
- Understand network segmentation and interdepartmental communication.
- Test connectivity and troubleshoot network issues.
